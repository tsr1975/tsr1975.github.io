Política de privacidad

Outliers · Kontado — actualizada el 24 de octubre de 2026

Qué datos usa

Con permiso de solo lectura de la cuenta que gestiona el canal Kontado, Outliers lee de las API de YouTube (YouTube Data API y YouTube Analytics API) las estadísticas de ese canal y de sus vídeos: vistas, tiempo de visualización, retención, suscriptores, impresiones, fuentes de tráfico e ingresos estimados. No lee datos de espectadores concretos ni de ningún otro canal o cuenta.

Para qué

Solo para que el propio canal vea cómo funcionan sus vídeos. Los datos no se venden, no se ceden a nadie y no se usan para publicidad. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde se guardan

En un servidor privado del titular del canal, sin acceso desde internet. El permiso de acceso se guarda en ese servidor con acceso restringido al titular.

Cómo retirar el permiso

En cualquier momento desde la página de permisos de tu cuenta de Google. Al retirarlo, Outliers deja de leer datos; los ya guardados se borran a petición.

También rige la política de YouTube y la política de privacidad de Google.
